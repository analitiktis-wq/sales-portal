* КТУ (Коэффициент трудового участия) — итоговая оценка вашей эффективности с учётом нагрузки, активности и результата. Значение выше 1.0 означает что вы работаете эффективнее среднего по команде.

** KPI (Интегральная оценка) — показывает насколько ваши конверсии выше или ниже среднего по команде. Значение 1.0 = вы на уровне команды, выше 1.0 = лучше среднего, ниже = есть зоны роста. Формула: взвешенная сумма ваших конверсий относительно средних по команде за месяц.

Вводите: Звонки · Клиенты · Встречи · Брони · Покупатели · Целевые покупатели · Коэф. присутствия
Конверсии (автоматически): C1=Встречи/Клиенты · C2=Брони/Клиенты · C3=Покупатели/Брони (макс.100%) · C4=Покупатели/Клиенты · C5=Целевые/Клиенты
KPI* = 0.20×(C1/C̄1) + 0.25×(C2/C̄2) + 0.25×(C3/C̄3) + 0.10×(C4/C̄4) + 0.20×(C5/C̄5) · C̄ — среднее по команде · если целевых нет — вклад C5=0
Кнагруз = Клиенты / Среднее клиентов  ·  Кактив = 0.5×(Звонки/Ср.звонков) + 0.5×(Встречи/Ср.встреч)  ·  Крез = Покупатели / Среднее покупателей
КТУ = KPI × (0.4×Кнагруз + 0.3×Кактив + 0.3×Крез) / (0.5 + 0.5×Кприсут)
